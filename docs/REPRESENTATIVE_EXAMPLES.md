## Reglas del registro

- No incluir el archivo ni una URL real en este documento.
- No asumir que permiso de procesamiento incluye demostración o marketing.
- Usar identificadores opacos y minimizar nombres o metadata.
- Registrar revocaciones, restricciones y eliminación.
- No publicar transcripts, resultados, métricas ni nombres sin autorización
  expresa.
- Conservar ejemplos negativos y fallidos cuando su autorización lo permita.
- Marcar como no disponible cualquier ejemplo vencido, revocado o eliminado.
- Relacionar cada medición con el ID del ejemplo, nunca con su ubicación privada.

Crear el registro no satisface el criterio de ejemplos representativos: deben
seleccionarse, autorizarse, utilizarse y revisarse ejemplos reales.
